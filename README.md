# Родник — сайт литературного объединения г. Майского

Сайт объединения «Родник» при центральной библиотеке города Майского.  
Опубликован на GitHub Pages по адресу `https://rodnik.github.io` (или через `pharma-news.github.io/rodnik`).

## Структура файлов

```
rodnik/
├── index.html         # Главная страница
├── .nojekyll          # Отключает Jekyll-обработку (обязательно!)
├── README.md
├── assets/
│   ├── logo.svg       # Логотип (опционально)
│   └── cover.jpg      # Обложка (опционально)
└── poets/
    ├── barieva.html   # Страница Людмилы Бариевой
    └── ...            # Другие авторы
```

## Как добавить нового автора

1. Скопируйте `poets/barieva.html` в новый файл, например `poets/ivanova.html`.
2. Замените имя, биографию и список публикаций.
3. В `index.html` добавьте карточку автора в раздел `#poets`.

## Запуск локально

```bash
python3 -m http.server 8000
# Откройте http://localhost:8000
```
