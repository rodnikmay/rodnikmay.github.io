❄️ KeyRush: Эльза

+1 Speed Keyboard Escape

Эльза бежит по гигантской конфетно-шоколадной клавиатуре. Каждая реально нажатая клавиша даёт +1 Speed — чем больше Speed, тем дальше она перепрыгивает провалы и тем шире провалы открываются. Уровни собраны как трассы-полосы: разгон, прыжок через провал, смена ряда, движущаяся клавиша, чекпоинт, финиш. Падение не отнимает Speed — оно возвращает на последнюю безопасную точку.

Камера всегда смотрит вперёд по трассе: W / ↑ — бег по клавишам, A/D / ←→ — переход в соседний ряд, Space — прыжок (зажми, чтобы прыгать подряд). ПКМ или свайп — немного повернуть камеру, колесо — приближение. Esc — пауза, R — назад на безопасную точку.

🗺 Уровни

Требование уровня — это Speed, которого хватает, чтобы перепрыгнуть самый широкий провал.
